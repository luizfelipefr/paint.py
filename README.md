# 🎨 Paint Luiz Felipe

Um software de desenho minimalista e moderno desenvolvido em **Python**, focado em manipulação de eventos e interfaces gráficas.

### 🛠️ Tecnologias
* **Python**
* **Tkinter** (Interface Gráfica)

### ✨ Funcionalidades
* **Desenho Livre:** Linhas fluidas com `capstyle` arredondado.
* **Seletor de Cores:** Integração com `colorchooser`.
* **Ajuste de Traço:** Controle deslizante para espessura da linha.
* **Interface Dark:** Estilização personalizada em modo escuro.

### 🚀 Objetivo
Projeto prático para consolidar conceitos de Engenharia de Software e lógica de programação, parte da minha trilha de aprendizado para me tornar um desenvolvedor **Full Stack**.
